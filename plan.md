# CyberVPN для Android — план

## Реализация
Создать русскоязычное Expo/React Native приложение: основной экран подключения, список серверов с Hysteria2-конфигурациями, загрузка README репозитория sociocyber1/txt при запуске и сохранение последнего списка локально. Исходный проект CyberVPN — desktop Rust для Linux/Windows, поэтому Android-туннель реализуется отдельным локальным Expo native module. Модуль запускает Android `VpnService`, запрашивает системное VPN-разрешение, строит TUN и запускает Hysteria2-core из GPL-3.0-компонентов Bedlam; статус UI должен отображать только подтверждённое нативное состояние. Минимальная Android API — 29. Нативный Android APK не считается проверенным без сборки и проверки на устройстве.

Кнопка поддержки раскрывает заданное сообщение и реквизиты; в ней же есть «Другие проекты» со ссылкой на CyberCord (`https://github.com/sociocyber1/CyberCord`) и контакты автора. Тап по реквизитам открывает простой выбор: скопировать номер карты, открыть установленное приложение Сбер (если ссылка поддерживается) или открыть его для перехода к СБП; если приложение не открывается, оставить возможность скопировать номер. Не запускать платеж и не утверждать, что банковский deep link предварительно заполняет перевод.

Пользовательский DNS позволяет выбрать сервер из каталога публичных Cloudflare, Google Public DNS и Quad9 по текущему UDP/TCP/DoT/DoH транспорту. Предустановка добавляет только подходящие значения в пользовательский список (общий максимум 8 адресов), а применение требует сохранения настройки.

NoToVPN — пуст по умолчанию; включение пустой политики не добавляет маршруты. Только явно заданные пользователем зоны и сайты могут маршрутизироваться напрямую, а изменение сохранённых правил применяется после переподключения, не пересоздавая активный туннель.

## Дизайн
Сохранить прежний утилитарный минимализм: мягкий холодный светло-голубой фон, белые панели, насыщенный синий для действий и зелёный только для подтверждённого активного состояния. Вертикальная композиция подходит для управления одной рукой; статус и одно главное действие визуально приоритетны, сервер и дополнительные настройки остаются компактными панелями ниже. Три нижние вкладки — «VPN», «Firewall», «Соединения». Использовать bundled MaterialCommunityIcons/векторные формы, не Unicode-глифы. Анимация кнопки соединения — короткий мягкий пульс только в состояниях ожидания, без блокирования жестов. Типографика — системный шрифт Android с ясной иерархией и короткими русскими подписями. Марка — «Простой VPN-клиент с серверами Hysteria2 из открытого источника», характер — прямой, спокойный, лёгкий.

## VPNFirewall и live connections
Пользователь подтвердил вариант **настоящая блокировка выбранных приложений при активном CyberVPN**. Использовать список launchable-приложений с package name и меткой. Для запрета всех — allowlist только CyberVPN; для точечных запретов — disallowlist выбранных пакетов. Android `VpnService.Builder` в одиночку отправляет исключённые приложения через системную сеть, а не блокирует; поэтому firewall запрещён к включению, пока Android не сообщает `isLockdownEnabled() == true`. Пользователю нужна системная настройка Always-on VPN + Block connections without VPN; отключённые/внесённые из VPN пакеты будут заблокированы Android lockdown. Не считать простую per-app маршрутизацию firewall.

Отдельно пользователь может явно исключить выбранные приложения **из VPN** для сайтов, блокирующих VPN exit IP. Их запросы используют обычную сеть и раскрывают адрес обычного подключения; не обещать защиту VPN для этого трафика. Список исключений сохраняется отдельно от блок-листа, редактируется только когда VPN отключён и применяется при следующем соединении через `addDisallowedApplication`. Режимы Firewall и VPN-exclusions взаимоисключаются. Android Lockdown блокирует трафик приложений вне VPN; при активном Lockdown нельзя обещать доступ исключённым приложениям, а восстановление туннеля должно показать явную ошибку.

Перед установкой TUN сохранить конфигурацию Hysteria URI и выбранную политику в app-private storage, чтобы системный Always-on запуск без extras мог восстановить VPN. При применении новых правил пересоздавать TUN; не подтверждать применение, если установление нового TUN или lockdown-проверка не прошли. Не позволять обычной кнопке «Отключить» отключать сервис, пока системный lockdown требует VPN.

Для списка «Соединения» использовать Android `ConnectivityManager.getConnectionOwnerUid()` из активного VpnService для TCP и UDP tuple, которые видны TUN. Сопоставлять UID с приложением только при успешном разрешении; показывать remote IP:port. Непроверенный UID отображать как «не определено», а не приписывать приложению. Сейчас экран хранит локальные события новых потоков, увиденных через TUN, не более 60 секунд; это не перечень всех системных sockets и не per-packet счётчик. Общая DNS-карта доменов в этом изменении не реализована, поэтому hostname не угадывать; DoH/DoQ, shared IP/CDN и прямой/вне-TUN трафик остаются ограничениями.

Для видимости приложений объявить только `<queries>` для `MAIN` + `LAUNCHER`, не широкое `QUERY_ALL_PACKAGES`, если каталога launchable-приложений достаточно. Интерфейс не загружает данные об установленных приложениях или потоках на сервер.

## Официальные технические основания
- Android VPN guide: per-app allow/disallow списки управляют тем, какие приложения используют VPN; приложения вне списка используют системную сеть, если ОС не блокирует non-VPN traffic. Lockdown — системный переключатель `Block connections without VPN`: https://developer.android.com/develop/connectivity/vpn
- `VpnService.Builder.addAllowedApplication` / `addDisallowedApplication`: excluded apps network as if VPN were not running; только один тип списка за раз: https://developer.android.com/reference/android/net/VpnService.Builder
- `VpnService.isAlwaysOn()` и `isLockdownEnabled()` дают сервису статус системного always-on/lockdown: https://developer.android.com/reference/android/net/VpnService
- `ConnectivityManager.getConnectionOwnerUid()` добавлен API 29, поддерживает TCP и UDP и возвращает `INVALID_UID`, если tuple не найден или владелец недоступен: https://developer.android.com/reference/android/net/ConnectivityManager
- Android 11+ фильтрует видимость установленных приложений; `<queries>` — более узкая альтернатива широкому разрешению: https://developer.android.com/training/package-visibility

## Структура
`app/(tabs)/index.tsx` — основной экран VPN; `firewall.tsx` — выбранные приложения и lockdown; `connections.tsx` — локальные live-flow записи. `app/(tabs)/_layout.tsx` создаёт нижнюю навигацию. `lib/vpn-native.ts` предоставляет Expo API. `modules/cybervpn-vpn/` содержит Expo bridge, Kotlin `VpnService`, manifest, per-app lists, connection owner attribution и TUN filtering в Go. `build-hysteria-aar.sh` генерирует AAR при Android-сборке. `app.config.ts` хранит minSdk 29 и branding metadata. `THIRD_PARTY.md` и `LICENSE` описывают GPL-3.0 и сторонние источники.
