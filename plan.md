# CyberVPN для Android — план

## Реализация
Создать русскоязычное Expo/React Native приложение: основной экран подключения, список серверов с Hysteria2-конфигурациями, загрузка README репозитория sociocyber1/txt при запуске и сохранение последнего списка локально. Исходный проект CyberVPN — desktop Rust для Linux/Windows, поэтому Android-туннель реализуется отдельным локальным Expo native module. Модуль запускает Android `VpnService`, запрашивает системное VPN-разрешение, строит TUN и запускает Hysteria2-core из GPL-3.0-компонентов Bedlam; статус UI должен отображать только подтверждённое нативное состояние. Минимальная Android API — 29. Нативный Android APK не считается проверенным без сборки и проверки на устройстве.

Кнопка поддержки раскрывает только заданное сообщение и реквизиты. Тап по реквизитам открывает простой выбор: скопировать номер карты, открыть установленное приложение Сбер (если ссылка поддерживается) или открыть его для перехода к СБП; если приложение не открывается, оставить возможность скопировать номер. Не запускать платеж и не утверждать, что банковский deep link предварительно заполняет перевод.

## Дизайн
Стиль: утилитарный минимализм с холодными светло-голубыми и графитовыми акцентами (вероятность 0.07); мягкая неоморфная панель управления (0.04); терминальная киберпанк-сетка (0.03). Выбран минимализм: ясный статус, один крупный элемент управления, свободное пространство. Цвета: почти белый/ледяной фон, насыщенный голубой для действий, зелёный только для подтверждённого состояния. Вертикальная композиция для одной руки; сервер и поддержка — компактные панели ниже переключателя. Анимации короткие и необязательные, без декоративных фоновых циклов. Системный шрифт Android, крупные статусы и короткие подписи. Марка: круглый символ соединённых узлов с разрывом в виде щита; фирменный голубой. Суть: «Простой VPN-клиент с серверами Hysteria2 из открытого источника», характер — прямой, спокойный, лёгкий. Голос: «Серверы обновлены» и «Скопировать номер карты».

## Структура
`app/(tabs)/index.tsx` — основной экран, выбор сервера, статус VPN и меню поддержки; `lib/config-feed.ts` — загрузка, нормализация и обновление URI из README; `lib/vpn-native.ts` — платформенный фасад подключения. `modules/cybervpn-vpn/` содержит Expo bridge, Kotlin `VpnService`, manifest, TUN builder и pinned Hysteria2 Go mobile binding; `build-hysteria-aar.sh` генерирует AAR при Android-сборке. `app.config.ts` хранит minSdk 29 и branding metadata. `THIRD_PARTY.md` и `LICENSE` описывают GPL-3.0 и сторонние источники.
