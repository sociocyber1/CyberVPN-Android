# CyberVPN brand typeface

`lmsans10-regular.otf` is the unmodified Latin Modern Sans 10 Regular OpenType face, bundled locally for the `SocioCyberneering Inc.` wordmark. It is based on the Computer Modern fonts used in TeX/LaTeX. The font family and the distinctive tracking are chosen to echo the supplied wordmark reference; this is a style match, not a claim that the reference image's original font has been identified.

The font came from the Ubuntu `fonts-lmodern` package, version `2.005-1`. It may be distributed under the GUST Font License, an instance of LPPL 1.3c or later. The complete license text is in `GUST-FONT-LICENSE.txt`. The binary was copied without modification.
